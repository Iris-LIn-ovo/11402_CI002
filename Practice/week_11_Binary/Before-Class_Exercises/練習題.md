2. 基礎：從走訪還原樹 (最常考！)
✅UVa 12347 - Binary Search Tree

題目大意：給你一串數字，這串數字是某棵 BST 的 前序走訪 (Pre-order) 結果。請你輸出這棵樹的 後序走訪 (Post-order)。

核心觀念：

你不需要真的把樹蓋出來。利用 BST 的特性：前序的第一個點是根節點，剩下的點中，比根節點小的在左邊，大的在右邊。

利用遞迴不斷切分左子樹與右子樹。

難易度：⭐⭐（這題是明天考試的「超級重點」）。

3. 中階：判斷與特性
✅UVa 536 - Tree Recovery

題目大意：給你一棵二元樹（不一定是 BST）的 前序 (Pre-order) 和 中序 (In-order)，求 後序 (Post-order)。

核心觀念：

前序找根，中序分左右。

這題雖然是普通二元樹，但如果你掌握了這一題，BST 的所有變體你都能秒殺，因為 BST 的中序就是「排好序的數列」。

難易度：⭐⭐⭐

4. 進階：結構與操作
UVa 10226 - Hardwood Species

題目大意：給你一大堆樹木名稱，統計每種樹出現的比例，並按名稱的字母順序輸出。

核心觀念：

雖然這題可以用 std::map 輕鬆解決，但 map 底層其實就是一棵「紅黑樹」（一種平衡的 BST）。

如果你想練習 BST，可以試著自己動手寫一棵 BST 來插入字串，最後用 中序走訪 印出結果，這樣就會是字典序。

難易度：⭐⭐⭐
