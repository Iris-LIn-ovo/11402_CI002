✅1. 最基礎的網格路徑：UVa 10074 - Take the Land
主題：最大全 1 矩陣 / 網格最佳化

題目大意：給你一個 M×N 的矩陣（由 0 和 1 組成），0 代表空地，1 代表樹木。你想買一塊「完全沒有樹木（全為 0）」的最大長方形土地，求它的最大面積。

為什麼是 2D DP？：你可以用一個 2D 陣列 dp[i][j] 來記錄到目前格子為止，向上連續有多少個空地。

難易度：⭐⭐

2. 經典雙字串模型：UVa 10405 - Longest Common Subsequence (LCS)
主題：最長共同子序列（必考經典！）

題目大意：給你兩個字串，找出它們最長的共同子序列的長度（子序列不需要連續，但相對順序要相同）。例如 abcde 和 ace 的 LCS 是 ace，長度為 3。

2D DP 邏輯：

宣告 dp[i][j] 代表字串 A 前 i 個字元與字串 B 前 j 個字元的 LCS 長度。

狀態轉移方程：

如果 A[i]==B[j] → dp[i][j] = dp[i-1][j-1] + 1 (來自左上角)

如果不相等 → dp[i][j] = max(dp[i-1][j], dp[i][j-1]) (來自上面或左邊)

難易度：⭐⭐⭐

3. 字串轉換代價模型：UVa 562 - Dividing coins (或 UVa 164 - String Computer / 這裡推薦經典的背包變體)
既然主題是 2D DP，絕不能漏掉 0/1 背包問題 (0/1 Knapsack)。雖然背包問題可以用 1D 陣列優化，但它的核心靈魂是 2D 陣列。

UVa 562 - Dividing coins

主題：0/1 背包問題變體

題目大意：有一堆硬幣，每枚硬幣有自己的價值。要把這堆硬幣分給兩個人，求兩個人分到的金額差值最小是多少？

2D DP 邏輯：

dp[i][j] 代表考慮前 i 個硬幣時，能否湊出總金額 j（布林值 true/false）。

目標是找出最接近總金額一半（sum / 2）的可能組合。

難易度：⭐⭐⭐

4. 進階矩陣操作：UVa 108 - Maximum Sum
主題：最大子矩陣和 (Maximum Submatrix Sum)

題目大意：給你一個 N×N 的整數矩陣（裡面有正數有負數），請你找出一個子矩陣，使得這個子矩陣裡面所有數字的總和最大。

2D DP 邏輯：

這題是 1D 最大子序列（Kadane's Algorithm）的 2D 進階版。

我們可以利用 2D DP 先做前綴和 (Prefix Sum) 降維，把二維矩陣壓縮成一維，再用 1D DP 去解。

難易度：⭐⭐⭐⭐
